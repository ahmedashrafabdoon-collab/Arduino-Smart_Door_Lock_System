📌 Overview

This project is a simple smart door lock system built using Arduino and an RFID module (RC522).
It simulates a real-world access control system using a servo motor to represent a door.

⚙️ Features

- RFID card authentication
- Green LED + buzzer feedback for valid access
- Red LED + buzzer feedback for invalid access
- Servo motor to simulate door opening

🧰 Components Used

- Arduino
- RC522 RFID Module
- Servo Motor
- Buzzer
- LEDs (Red & Green)
- Resistors
- Jumper wires

🚀 How It Works

1. The user scans an RFID card
2. The system checks if the card ID is authorized
3. If valid:
   - Green LED turns on
   - Buzzer beeps twice
   - Servo motor opens the door
4. If invalid:
   - Red LED turns on
   - Buzzer makes a long beep twice

🎯 Purpose

This project demonstrates how to integrate multiple hardware components into a functional embedded system using low-cost materials.
